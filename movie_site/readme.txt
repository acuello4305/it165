MovieRate is a movie review website that I created using the MERN stack.
Users can create an account, login, search for movies, and write reviews.

Features
- Sign up
- Login and logout
- Search for movies
- View movie posters
- Write a movie review
- Rate movies from 1 to 5 stars
- Edit your reviews
- Delete your reviews
- View reviews from other users

Technologies Used
- MongoDB
- Express
- React
- Node.js
- JavaScript
- CSS
- Movie API (OMDb API )

 How It Works
Users first create an account and login. After logging in, they can search for a movie and write a review.

The review includes:
- Movie title
- Movie poster
- Rating
- Opinion

The reviews are saved in MongoDB and displayed on the Home page.

Users can edit or delete their own reviews.

CRUD
- Create - Add a review
- Read - View reviews
- Update - Edit a review
- Delete - Delete a review
